# Clairlens | Advanced Optical Lens Manufacturing

Official web application for **Clairlens Optical Manufacturing AG** (Zurich, Switzerland).

## Features

- **Executive Brand Overview**: Executive showcase of Clairlens optical technology, refractive indices, and nano-coating matrices.
- **Dedicated Subpages**:
  - **About Clairlens**: Brand story, 6-stage ISO 13485 cleanroom manufacturing timeline, and technology matrix.
  - **Products / Lens Range**: Complete catalog with live category filtering, search, Abbe clarity metrics, and interactive spec viewer modal.
  - **Contact Us**: Official communication desk, distribution partner inquiry form with validation, and Zurich facility map.
- **Interactive Lens Index Visualizer**: Interactive refractive index comparison (1.50 through 1.74) with thickness cutaways.
- **Glassmorphism Design System**: Built with modern CSS variable tokens, Deep Wine palette (`#612E3E` & `#351720`), and responsive typography (Poppins, Inter Variable, Roboto).

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React

## Development Setup

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build
```
